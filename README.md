# Library System

## Description
Simple Library Information System

## Requirements
- PHP
- Composer
- MySQL
- Laravel

## Installation
1. Clone repository: git clone <URL_REPOSITORY_GITHUB_ANDA>
2. Masuk direktori: cd library-system
3. Install dependency: composer install
4. Salin file environment: cp .env.example .env
5. Generate key: php artisan key:generate
6. Konfigurasi database di file .env
7. Jalankan migrasi: php artisan migrate
8. Jalankan server: php artisan serve
